# Chess upsets over the board (DA2402, IIT Madras)

Team: consult kid + hack coord + high iq

Everything for the project is in the `submission/` folder. Start with [submission/README.md](submission/README.md): it describes the folder layout, how to run the four notebooks and the dashboard, and where to download the raw data.

* `submission/notebooks/`: 01 collection, 02 cleaning and storage, 03 model, 04 report
* `submission/dashboard/`: the interactive Dash app
* `submission/viz/`: figures used by the report and the dashboard
* `submission/reports/`: cleaning log, data dictionary and other small tables
